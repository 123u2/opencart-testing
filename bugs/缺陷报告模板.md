# Bug 报告模板

> 面试可讲：规范的 Bug 报告包含 9 个要素，确保开发能一步到位复现

---

## 模板格式

```
============================================================
【Bug ID】     BUG-{XXX}
【标题】       {一句话描述问题现象，含操作+结果，如"XX页面XX操作后显示XX而非XX"}
【严重程度】   {Critical / High / Medium / Low}
【优先级】     {P0 / P1 / P2 / P3}
【环境】       {浏览器版本 / OS / 被测系统版本}
【前置条件】   {复现之前需要满足的状态}
【复现步骤】
  1. {具体操作步骤1}
  2. {具体操作步骤2}
  3. ...
【实际结果】   {当前系统的实际行为}
【预期结果】   {根据需求/逻辑应有的行为}
【附件】       {截图/录屏/日志链接}
============================================================
```

---

## 严重程度定义

| 等级 | 定义 | 示例 |
|------|------|------|
| Critical | 系统崩溃/数据丢失/核心流程阻断 | 结账确认后报500、支付成功但订单未生成 |
| High | 核心功能异常但可绕过 | 登录失败、搜索结果空白 |
| Medium | 非核心功能异常/UI错位 | 分页按钮失效、移动端布局错乱 |
| Low | 轻微UI瑕疵/文案错误 | 拼写错误、图标偏色 |

## 优先级定义

| 等级 | 定义 |
|------|------|
| P0 | 立即修复，阻塞上线 |
| P1 | 本迭代必须修复 |
| P2 | 下迭代修复 |
| P3 | 排期修复，可延后 |

## 示例 Bug 报告

### BUG-001

```
============================================================
【Bug ID】     BUG-001
【标题】       购物车页面修改商品数量为-1并更新后，数量变为0而非错误提示
【严重程度】   Medium
【优先级】     P2
【环境】       Chrome 120 / Windows 10 / OpenCart 4.0.2.3 / Docker
【前置条件】   购物车中有至少1件商品
【复现步骤】
  1. 浏览任意商品详情页，点击 Add to Cart
  2. 进入购物车页面 (Shopping Cart)
  3. 将商品数量的输入框值改为 -1
  4. 点击 Update (更新) 按钮
【实际结果】   商品数量变为 0，但商品仍显示在购物车中，小计为 0
【预期结果】   应提示 "Quantity must be at least 1"，数量恢复为修改前的值
【附件】       screenshots/bug-001.png
============================================================
```

### BUG-002

```
============================================================
【Bug ID】     BUG-002
【标题】       搜索框输入 SQL 注入字符串后，搜索结果页显示数据库错误信息
【严重程度】   High
【优先级】     P1
【环境】       Chrome 120 / Windows 10 / OpenCart 4.0.2.3
【前置条件】   无
【复现步骤】
  1. 打开网站首页
  2. 在顶部搜索框中输入: '; DROP TABLE oc_product; --
  3. 点击 Search 按钮
【实际结果】   页面显示 MySQL 错误信息，暴露出数据表前缀 "oc_"
【预期结果】   系统应安全处理输入，显示 "没有匹配的商品" 或忽略特殊字符
【附件】       screenshots/bug-002.png
============================================================
```

### BUG-003

```
============================================================
【Bug ID】     BUG-003
【标题】       注册时密码输入3位字符，系统无前端校验，提交后报后端错误
【严重程度】   Low
【优先级】     P3
【环境】       Chrome 120 / OpenCart 4.0.2.3
【前置条件】   无
【复现步骤】
  1. 打开注册页面
  2. 所有必填字段填写合法值
  3. Password 输入 "Ab1" (3个字符)
  4. 点击 Continue
【实际结果】   页面刷新后显示 "Password must be between 4 and 20 characters!"
【预期结果】   建议在前端密码框失焦时即给出长度提示，而不是提交后才报错
【附件】       screenshots/bug-003.png
============================================================
```

## 附：Bug 生命周期（面试常考）

```
        ┌─────────┐
        │  New    │  测试提交
        └────┬────┘
             ↓
        ┌─────────┐
        │ Assigned│  PM/Lead 分配
        └────┬────┘
             ↓
        ┌─────────┐
        │  Open   │  开发确认并开始修复
        └────┬────┘
             ↓
        ┌─────────┐      ┌──────────┐
        │  Fixed  │ ←──→ │ Reopened │  (修复未通过验证)
        └────┬────┘      └──────────┘
             ↓
        ┌─────────┐
        │ Verified│  测试验证修复
        └────┬────┘
             ↓
        ┌─────────┐
        │ Closed  │
        └─────────┘

特殊状态:
  - Duplicate: 与已有 Bug 重复 → Closed
  - Wont Fix: 开发确认不修复 (需理由) → Closed
  - Not a Bug: 确认为合理行为 → Closed
  - Deferred: 延期处理 → 下一版本
```
